## 1. Understanding the Futures Curve: Contango, Backwardation, and Roll Yield

### What is Roll Yield?

Roll yield is the return received (or paid) when rolling a futures contract from one expiry to another. It’s the difference between the price you paid to enter a futures contract and the price you receive when rolling into the next one — adjusted for the cost of carry.

In mathematical terms, for a long position rolled from contract A to contract B:

```
Roll Yield = (Price_B - Price_A) / Price_A
```

But this is only the *first-order approximation*. In reality, roll yield is decomposed into:

- **Carry Cost** — cost of holding the asset (storage, insurance)
- **Convenience Yield** — benefit of holding the physical commodity (e.g., hedging against supply disruption)
- **Market Sentiment & Volatility Premium** — driven by risk premium and liquidity

In 2026, algorithmic systems use this decomposition to build state machines that adjust position sizing and roll timing based on regime.

### Contango vs Backwardation: The Curve States

#### Contango (Forward Curve Slope Up)

> “Contango is the enemy of longs, the friend of shorts.”

In contango, futures prices are higher than spot prices. This implies a positive roll yield for shorts and negative roll yield for longs — unless the roll is offset by a positive convenience yield.

In 2026, commodities like crude oil, natural gas, and industrial metals spend most of their time in contango. This is driven by:

- High storage costs
- Low convenience yields
- High volatility regimes

Example: The VIX futures curve is 80% contango — generating 3–7% monthly roll yield for short positions.

#### Backwardation (Forward Curve Slope Down)

> “Backwardation is the sweet spot for longs — if you’re patient.”

In backwardation, futures prices are lower than spot prices. Roll yield is positive for long positions, negative for shorts. This signals:

- High convenience yield (e.g., physical commodity shortage)
- Low storage costs
- High demand for physical delivery

Backwardation is rare but powerful — think wheat, gold, and copper during supply shocks. 2026 saw back-to-back backwardation episodes in gold and copper during Q1–Q2 (driven by supply chain disruptions and inflationary pressures).

## 2. Detecting Regimes: The VIX/VIX3M Ratio as a Real-Time Signal

Algorithmic systems rely on regime detection to trigger roll actions. In 2026, the **VIX/VIX3M ratio** has become the de facto regime switcher for volatility futures.

### How it Works

- VIX: Implied volatility of the near-term 30-day futures
- VIX3M: Implied volatility of the 3-month futures

When VIX/VIX3M > 1 → **Contango regime** (volatility is expected to rise in the future → higher forward prices)
When VIX/VIX3M < 1 → **Backwardation regime** (volatility expected to decline → lower forward prices)

Real-time algorithmic systems use this ratio with a 30-day rolling window to trigger roll decisions:

```python
import pandas as pd

def detect_regime(vix_series, vix3m_series):
    """
    Detect contango vs backwardation using VIX/VIX3M ratio
    """
    ratio = vix_series / vix3m_series
    regime = ratio > 1.0  # True = contango
    return regime

# Example usage
vix = [15, 16, 17, 18, 19]
vix3m = [14, 15, 16, 17, 18]
regime = detect_regime(vix, vix3m)
```

## 3. Roll Yield Optimization: From Theory to Production

Rolling futures is not a one-size-fits-all process. In 2026, algorithmic systems use **multi-factor roll optimization** to maximize roll yield while minimizing slippage.

### The Roll Yield Decomposition

Roll yield = Convenience Yield - Storage Cost - Roll Slippage

In production systems, this is modeled as:

```python
def compute_roll_yield(current_price, next_price, storage_cost, convenience_yield, slippage):
    return (next_price - current_price) / current_price - storage_cost + convenience_yield - slippage
```

In 2026, slippage is modeled using **real-time bid-ask spreads** from the exchange (e.g., CME, ICE, EFP):

```python
def get_slippage(contract, exchange):
    # Fetch real-time bid-ask spread
    spread = exchange.get_spread(contract)
    return spread * 0.001  # 0.1% slippage per roll
```

## 4. Backtesting Regime-Aware Strategies

No algorithmic system is deployed without backtesting. In 2026, commodity futures traders use **regime-aware backtests** to validate roll yield strategies across multiple commodity classes.

### Example: Roll Yield Strategy Backtest (2026)

```python
import numpy as np
import pandas as pd

def backtest_roll_yield_strategy(prices, roll_frequency=1, regime_signal=None):
    """
    Backtest roll yield strategy using regime signals.
    """
    positions = []
    roll_yields = []

    for i in range(1, len(prices)):
        current_price = prices[i-1]
        next_price = prices[i]
        regime = regime_signal[i-1] if regime_signal else None

        if regime == 'backwardation':
            positions.append(1)  # long
        elif regime == 'contango':
            positions.append(-1)  # short

        roll_yield = (next_price - current_price) / current_price
        roll_yields.append(roll_yield)

    return np.array(roll_yields), np.array(positions)

print(f"Win Rate: {np.sum(positions * yields > 0) / len(positions):.2%}")
```
